# PDM省電力テスト測定手順

## 測定前に理解しておくこと

XIAO nRF54L15 SenseではマイクとIMUが`IMU&MIC_3V3`を共有しています。
そのため、IMUを動かしたままマイクのVDDだけを切ることはできません。
この測定では、PDMクロック停止後の電流が「IMUのみ」のS1まで戻るかを調べます。

重要な比較は次の3点です。

- S1: 共有レールON、加速度416 Hz、PDMクロックなしの目標基準
- S2: PDM録音中。S1より明確に高いことが測定成立の前提
- S3/S3D/S4/S5: クロック停止方法を段階的に強化した状態

各状態の`IMU proof`も確認してください。電流だけが下がり、IMU読み出しが失敗した
場合は「IMUを維持したままマイクを止めた」とは判定できません。

> **電池は絶対に接続しないでください。** 充電電流が測定値に加算されます。
> また、異なる電源をXIAOへ同時に接続しないでください。

## 安価なUSB電流計: ALIENTEK UT70

UT70の表示分解能は0.1 mAです。数百µA規模の差を見る用途には使えますが、
マイク単体が1 µAになったことまでは証明できません。

1. XIAOをMacへ直接接続し、ファームウェアとシリアル出力を確認します。
2. XIAOをMacから取り外します。
3. `安定したUSB 5 V電源 → UT70 → USB-Cケーブル → XIAO`と接続します。
4. 電池や2本目のUSBケーブルは接続しません。
5. UT70の表示をスマートフォンで動画撮影してからXIAOへ給電します。最初はS0です。
6. 各状態の先頭1秒を除き、その後の20秒で安定した値を読み取ります。
7. 2周、約5分を記録します。

UT70では0.2 mA以内を同等と扱います。まず`S2 - S1`が0.4 mA以上あることを
確認し、その後で停止状態をS1と比較してください。

| 観測 | 判定 |
| --- | --- |
| S3がS1の±0.2 mA以内、IMU正常 | 通常のDMIC STOPで十分 |
| S3は高いがS3DがS1と同等 | 明示的なsleep pinctrlが必要 |
| S3Dは高いがS4がS1と同等 | PDM_CLKのGPIO Low固定が必要 |
| S4もS2に近い | マイクが眠っていない、または別の負荷が残っている |
| S2とS1の差が明確でない | UT70では判定不能。結論を出さない |

## Nordic PPK2

波形と区間平均を正確に取る場合はSource Meterモードを5.0 Vに設定します。

1. PPK2の`DATA/POWER` USBをMacへ接続します。
2. Power ProfilerアプリでSource Meter、5.0 Vを選択します。
3. PPK2 `VOUT`をXIAO `5V`、PPK2 `GND`をXIAO `GND`へ接続します。
4. XIAO側のUSBとすべての電池が外れていることを確認してからDUT電源を有効にします。
5. 2周記録し、各状態の先頭1秒を除いた20秒間の平均値を求めます。

PPK2出力とXIAOのUSB電源を同時に接続しないでください。

## µAレンジのあるテスター

S2の最大電流を測れる固定レンジを選び、測定中は切り替えません。

1. 安定した絶縁5 V電源を用意します。
2. 電源プラスをテスターの電流入力へ接続します。
3. テスターのCOM側をXIAO `5V`へ接続します。
4. 電源GNDをXIAO `GND`へ直接接続します。
5. XIAOへ給電する前にレンジを選択します。

レンジ切替時の瞬断でXIAOがリセットされ、S0から再開する場合があります。
テスターの負担電圧でXIAOの電圧が下がる場合は、上位レンジか別の測定器を使います。

## 一般的なUSB電流計

安価なUSB電流計は0.1 mAまたは1 mA分解能の場合があります。充電IC、LDO、
ボード上の回路、電流計自身のオフセットが含まれるため、絶対値は評価しません。

同じ周回内の`S2`と`S3/S3D/S4`の差だけに注目してください。S2と停止状態の差が
表示の最小桁2カウント未満なら判定不能です。機材を変えて再測定します。

## 記録表

| 状態 | 1周目 | 2周目 | IMU proof | メモ |
| --- | ---: | ---: | --- | --- |
| S0 | | | 対象外 | 共有レールOFF |
| S1 | | | 成功/失敗 | IMUのみの目標基準 |
| S2 | | | 成功/失敗 | PDM録音中 |
| S3 | | | 成功/失敗 | STOPのみ |
| S3D | | | 成功/失敗 | CLK/DIN切断 |
| S4 | | | 成功/失敗 | CLKをLow固定 |
| S5 | | | 成功/失敗 | suspend結果もシリアルに記録 |

測定後は判断済みの結論だけでなく、生の電流値と測定器名を報告してください。

最終結論は次のどちらかで記録します。

- 「マイクVDDはONのままだが、測定電流はIMUのみのS1基準まで戻った」
- 「クロックを停止しても測定電流はS1基準まで戻らなかった」
