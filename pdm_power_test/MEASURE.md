# PDM省電力テスト 測定手順（ALIENTEK UT70）

## 測定対象

このテストはXIAO nRF54L15 SenseのUSB 5 V入力で、次の2つの差を測ります。

- 共有`IMU&MIC_3V3`電源をOFFからONにした差
- IMUをpower-downしたまま、マイクをsleepからactiveへ切り替えた差

表示値は基板全体の消費電流です。マイク単体やIMU単体の絶対電流ではありません。

> 電池は接続しないでください。充電電流が測定値へ加わります。
> USBと外部電源を同時に接続しないでください。

## 状態シーケンス

| 各周の時間 | 状態 | 共有電源 | IMU | マイク |
| ---: | --- | --- | --- | --- |
| 0〜20秒 | S0 | OFF | OFF | OFF |
| 20〜40秒 | S1 | ON | ODR 0 | sleep |
| 40〜60秒 | S2 | ON | ODR 0 | active |

60秒後はS0へ戻ります。LEDは全状態で消灯し、通常版ではUARTの`>>> STATE`行で
状態を確認します。

## 測定手順

1. 電池を外し、`USB電源 → UT70 → USB-Cケーブル → XIAO`の順に接続する。
2. UT70を波形表示へ切り替える。
3. 通常版では`python3 capture.py`を実行し、UARTの状態時刻を記録する。
4. 最低5周（5分）測定する。
5. 各遷移後2秒を除外し、プラトー中央の値を記録する。
6. 各周の`S1 - S0`と`S2 - S1`を計算する。

状態切替時にはロードスイッチ、I²C、PDM、UARTによる短い過渡があります。
判定には遷移直後ではなく安定した区間を使用してください。

## 判定

| 比較 | 含まれる主な負荷 |
| --- | --- |
| S1 − S0 | 共有ロードスイッチ、power-down中のIMU、sleep中のマイク、I²Cプルアップ |
| S2 − S1 | マイクactive、nRF54 PDM peripheral、PDMクロック、DMA起床 |

UT70の表示が0.001 A刻みなら、1 mAの差は1カウントです。単発の値ではなく、
同じ向きの段差が複数周で再現することを確認してください。

| 周 | S0 [mA] | S1 [mA] | S2 [mA] | S1 − S0 [mA] | S2 − S1 [mA] |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

## ノイズを減らす場合

USB-C経由ではATSAMD11デバッグMCUやUSB電源回路も測定されます。差が見えない場合は、
ファームウェアを書き込んだ後にUSB-Cを外し、XIAOのVBUS/GNDパッドから給電します。

静音版はUARTもLEDも無効です。リセット時点を波形へ記録し、20秒区切りから状態を
特定できる場合だけ使用してください。それでも差が見えない場合はPPK2など、より
高分解能の測定器を使用します。
